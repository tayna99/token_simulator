# 부트캠프 리서치 메시지 모음

작성일: 2026-05-24
실행: Day 1 (월) 안에 두 메시지 모두 발송.
원칙: 영업 톤 금지. *리서치 활동*임을 분명히. 운영진 양해를 *먼저* 받은 뒤 팀 메시지 발송.

---

## 1. 운영진/강사용 1:1 메시지 (먼저 보낼 것)

```
안녕하세요 [강사/운영진 이름]님,

부트캠프 진행하시느라 고생 많으십니다.

다름이 아니라, 제가 평소에 AI/LLM 사용량과 비용 관리 쪽 제품 기획을
공부하고 있는데, 이번 부트캠프가 "팀별로 API 예산이 주어지고, 그걸
어떻게 쓰고 모니터링할까"를 관찰하기에 정말 좋은 환경이라는 생각이
들었습니다.

그래서 부트캠프 운영에 방해되지 않는 선에서 짧은 리서치를 해보고
싶은데요, 미리 양해를 구하려 합니다.

하려는 것은 이렇습니다.

- 팀별 1명에게 10분 정도 짧은 인터뷰 (3~5팀, 자율 신청)
- 질문은 "API 비용을 어떻게 예측/관리할 계획인지"
- 제품 판매나 영업 목적은 전혀 아니고, 같은 부트캠프 안에서
  사례 관찰만 하는 리서치입니다.
- prompt 같은 민감 정보는 수집하지 않고, 사용 패턴/관리 방식만
  물어봅니다.

그리고 부트캠프 운영 관점에서 한 가지 여쭤보고 싶은 게 있는데,
혹시 팀별 API 사용량/잔액/주요 사용처가 한 화면에서 보이는 자료가
있다면 운영에 도움이 되실까요? (이것도 약속이 아니라 의견만
여쭙는 거예요.)

답변 부담 없으셔도 됩니다. 그냥 "리서치하는구나" 정도로만
인지해주셔도 충분합니다.

감사합니다.
```

**왜 이 톤인가**
- "영업 아님" 두 번 강조 — 같은 부트캠프 안에서 가장 위험한 오해.
- 운영진 인터뷰는 *옵션*으로 슬쩍 제안 — 즉답 부담 없게.
- "약속이 아니라 의견만" — 운영진이 *공식 요구*로 받아들이는 리스크(B5) 차단.

**운영진 답변 결정 분기**
- ✅ "괜찮아요" → 즉시 §2 팀 메시지 발송.
- 🟡 "내용 더 듣고 싶다" → 짧은 통화/대면. 부담 줄이려 *가짜 리포트 1장*만 첨부.
- ❌ "부트캠프 안에서는 자제해 주세요" → *부트캠프 외* 본인 네트워크로 인터뷰 대상 전환. 깔끔히 철수.

## 2. 팀 채널/그룹 메시지 (운영진 OK 받은 뒤)

```
안녕하세요!

이번 팀 프로젝트에서 OpenAI API랑 ChatGPT Business 공용 계정을
지원받게 되어서, 팀들이 실제로 AI/API를 어떻게 쓰고 비용이나
사용량을 어떻게 관리할지 간단히 조사해보고 있습니다.

(미리 [운영진 이름]님께 양해는 구했어요!)

저는 평소에 AI SaaS 비용/사용량 관리 제품 기획을 공부하고
있어서요. 혹시 각 팀에서 10분 정도만 짧게 이야기 나눌 수 있을까요?

물어보고 싶은 건 복잡한 건 아니고:

- API를 어떤 기능에 쓸 예정인지
- 10만 원 한도를 어떻게 관리할 것 같은지
- 어떤 기능이 비용을 많이 쓸 것 같은지
- 팀 프로젝트 끝날 때 AI 사용 리포트가 있으면 도움이 될지

이 정도입니다.

제품 판매나 영업 목적은 아니고, 팀 프로젝트 과정에서 실제 문제를
관찰해보려는 리서치입니다.

답례로 인터뷰 끝난 뒤 팀별 가상 사용 데이터로 만든 "AI 사용
리포트 샘플" 1장 보내드릴게요 (강제 아니고, 보고 싶으면!).

DM 주시거나 이 메시지에 이모지로 신청해주세요.
```

**왜 이 톤인가**
- "운영진께 양해 구했어요" — 사회적 안전망(B1) 강화.
- "이모지로 신청" — 응답 마찰 최소.
- "리포트 샘플은 보고 싶으면" — 옵트인. 영업 압박 0.
- 4개 질문 미리 공개 — 인터뷰가 *간단한 일*임을 시그널링.

## 3. 인터뷰 일정 잡기 (DM 답변 후)

```
신청 감사합니다!

다음 중 편한 시간 알려주실 수 있을까요?

- [Day 2 오전 슬롯 1]
- [Day 2 오후 슬롯 2]
- [Day 3 오전 슬롯 1]
- [Day 3 오후 슬롯 2]

비대면 통화/디스코드/음성 채팅 다 가능합니다. 텍스트로
하시는 것도 OK예요 (좀 더 느리지만요).

10분 정도 예상하고, 답변 정리 메모는 익명으로만 남깁니다.
```

**팁**: 슬롯 4개 미리 던지면 *추가 핑퐁 1라운드 절약*. 다 안 맞으면 그때 협상.

## 4. 인터뷰 직후 감사 메시지 + 리포트 전달

```
오늘 인터뷰 정말 감사했습니다!

말씀해주신 내용으로 [팀명]이 OpenAI API를 4주간 썼다고 가정하고,
가상 사용 데이터로 1장짜리 리포트를 만들어봤어요. 첨부합니다.

[리포트 PNG 첨부]

이런 형식이 발표나 운영에 어떨까요? 어색하거나 빠진 항목이
있으면 알려주세요.

추가로 한 가지만 더 여쭤봐도 될까요?

> 만약 이런 기록을 SDK 한 줄로 자동 수집해주는 도구가 있다면,
> 한 달에 1만 원 정도면 쓸까요?

답변 부담 없으셔도 됩니다. "잘 모르겠다"도 좋은 답이에요!
```

**왜 이 메시지가 중요한가**
- *진짜 데이터로 만든 리포트*를 받아본 직후 = 가장 솔직한 반응.
- WTP 약신호 한 질문: "1만 원 정도면 쓸까요?" — 직접 가격 아니라 *반응 강도* 측정.
- "잘 모르겠다도 좋은 답" — 가짜 긍정 답변 차단.

## 5. 운영진 결과 공유 메시지 (Day 4 저녁)

```
지난번 양해해주셔서 감사했습니다.

부트캠프 팀 3~5팀 인터뷰를 마쳤고, 운영진 관점에서 도움이 될
수도 있는 자료를 한 장 만들어봤습니다.

[팀별 종합 대시보드 캡처]

- 팀별 4주 누적 사용량 추정
- 예산 소진율 상위/하위 팀
- 비용이 많이 나오는 기능 패턴 3가지

가상 데이터로 만든 자료지만, 만약 실제 운영에 이런 화면이
있으면 도움이 되실지 의견 주시면 감사하겠습니다.

(다시 한 번, 이건 공식 도구 약속이 아니라 의견 구하는
리서치 자료입니다.)
```

**왜 이 톤인가**
- "공식 도구 약속 아님" 재확인 — B5 리스크 차단.
- *질문 1개*만 — 운영진 시간 절약.

## 6. 안 할 메시지 (Anti-template)

다음 표현은 *절대* 쓰지 말 것:

- ❌ "저희 제품"
- ❌ "유료/구독"
- ❌ "베타 테스터 모집"
- ❌ "출시 예정"
- ❌ "이 기능 어떠세요?" (→ "이런 정보가 있으면 어떠세요?"로 바꿈)
- ❌ 가격을 직접 물음 ("얼마 내실래요?")
- ❌ "저희 회사" / "스타트업"

대신 쓸 표현:

- ✅ "제가 공부하는 분야"
- ✅ "리서치"
- ✅ "관찰"
- ✅ "의견"
- ✅ "이런 자료가 있다면"
